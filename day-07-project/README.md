# 🖥️ Full Calculator with Menu

**Date:** 9 October 2026

The program features a command-line interface (CLI) menu that provides various mathematical and logical operations. Upon running the application, the console displays the menu and waits for the user to input their choice

### 📋 Main Menu Options

When the program executes, the following menu is displayed on the console:

```text
===== Calculator Menu =====
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Remainder
6. Even/Odd Check
7. Find Largest Number
8. Exit

Choose an option:
```

### ⚙️ Supported Operations

- **Addition (1):** Calculates the sum of two or more numbers.
- **Subtraction (2):** Calculates the difference between two numbers.
- **Multiplication (3):** Calculates the product of numbers.
- **Division (4):** Divides one number by another (handles division by zero checks).
- **Remainder (5):** Finds the modulus/remainder of a division operation.
- **Even/Odd Check (6):** Checks whether a given number is even or odd.
- **Find Largest Number (7):** Compares multiple numbers to find the maximum value.
- **Exit (8):** Safely terminates the program execution.
